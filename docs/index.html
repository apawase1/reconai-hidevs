✅ CURRENT FEATURES — Live today

Everything below is already running in the real app, not a mockup — this static page just replays a captured trace so it can be viewed without connecting a Google account.

📥 Gmail discovery (readonly)

Scans your inbox — excluding Sent, Drafts, and Chats — for invoices, receipts, bills, and statements, with a readonly OAuth scope that can never send, delete, or modify anything.

🔍 Duplicate, recurring & budget checks

Flags duplicate charges, recurring subscriptions/investments, budget overruns, and bank-CSV debits with no matching invoice email — all before totals are calculated.

🏷️ Business vs personal tagging

Every transaction is tagged business, personal, or untagged in place — no need to keep separate accounts or inboxes to get the split.

📊 One-click Google Sheets export

Paste a Sheet ID once and every run auto-writes its report to that Sheet's first tab (overwriting, never appending). Skip the field and nothing is written — and mock/UI-testing runs never touch your Sheet either way.

📄 One-click PDF export

Download the full report — metrics, category breakdown, and the AI-written narrative — as a shareable PDF.

🔐 Real, single-click Google sign-in

Opens a genuine link in a new tab to pick your account — never a silently-blocked popup — and that tab closes itself the moment sign-in finishes.

👋 Smart greeting handling

A plain "hi" gets a short reply about what ReconAI does.

🛡️ Guardrails

Readonly Gmail scope, input/output filters, rate limiting, a destructive-action blocklist, and CSV sanitizing are active on every run.

🚀 FUTURE SCOPE — Planned Integrations

This hackathon build is deliberately scoped to one Gmail inbox + one bank statement per run, to keep API/compute usage inside budget — not because the rest is unbuilt. The tool-layer logic for all four of these already exists and is designed to extend this way with more headroom.

📂 Google Drive discovery

Scan Drive for receipts/invoices saved outside Gmail — downloaded PDFs, scanned bills — so Discovery isn't limited to what arrived by email.

🧾 Persistent, multi-month ledger

The Sheets export above is live and auto-writes every run today — the next step is a ledger that remembers what's already reconciled across runs, so the Reporting Agent can answer questions across multiple months instead of just this one.

🔗 Cross-account reconciliation

Match transfers between a user's own accounts (personal + business current, or a co-founder's inbox) instead of double-counting them as spend — mocked up below.

📈 Growth-strategy synthesis

Month-over-month spend-trend deltas, a cash-flow view netting spend against income, and reinvestment nudges — needs the persistent ledger above for multi-month history.

Cross-account reconciliation Roadmap — not in this build
